# Roadmap

## Versao 1

- Interface base com abas principais.
- Gerador de roteiro local por formulario.
- Checklist editorial local.
- Busca de cartas via Scryfall.
- Analisador simples de decklist.

## Versao 2

- Persistencia local dos projetos de video.
- Biblioteca de prompts do canal.
- Exportacao de roteiro para Markdown.
- Sistema de templates por formato: Shorts, deck tech, lore, review e top 10.

## Versao 3

- Backend com autenticacao.
- Banco de dados.
- Integracao com APIs de IA.
- Painel de calendario editorial.
- Publicacao e acompanhamento de videos.
